# Report writing

1. Read `template.md` (in this skill's folder, next to this file) with `read_file` and follow its structure exactly.
2. Keep the whole report under ~400 words.
3. Start with a one-paragraph **Summary** a busy reader can stop after.
4. **Key points**: 3–5 bullets, each one sentence, most important first.
5. **Details**: short paragraphs or a table; facts only, no filler.
6. **Conclusion**: one or two sentences with the takeaway or recommendation.
7. Write the report to the workspace path you were asked for (default `/report.md`).
